# Başvuru kontrol listesi

Bu dosya bir ödül kazanımı veya tam erişilebilirlik sertifikası iddiası değildir.

- [x] Tasarım: özgün SVG kimliği, iki font, malzeme merkezli art direction, editoryal yerleşim.
- [x] Kullanılabilirlik: görünür gezinme, koleksiyon kontrolleri, ürün/iletişim bağlantıları, gerçek 404, form geri bildirimi.
- [x] Yaratıcılık: iplikten bindallıya beş sahneli, doğal ve geri alınabilir kaydırma anlatısı.
- [x] İçerik: Türkçe metinler, sıfır Lorem Ipsum, uydurulmuş fiyat/kuruluş bilgisi/yorum yok, görsel kökeni açık.
- [x] Mobil: ayrı dikey koleksiyon, kısa hero, dokunma hedefleri, mobil menü ve ürün akışı.
- [x] Performans: WebP, responsive Next Image, yerel font, kritik ilk kare, kademeli sahne yükleme ve dinamik GSAP.
- [x] Erişilebilirlik uygulaması: semantik yapı, skip link, görünür odak, diyalog odağı, Escape, alt metin, azaltılmış hareket.
- [x] Animasyon: kontrollü crossfade/ölçek, çerçeve geçişi, SVG iplik, hafif bağlantı hareketi; native kaydırma korunur.
- [x] SEO: rota metadatası, canonical ayarı, sitemap/robots, gerçek bilgiyle Organization JSON-LD.
- [x] Sosyal metadata: Open Graph, Twitter, 1200×630 marka görseli, favicon, uygulama simgesi.
